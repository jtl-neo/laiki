# 來記 Laiki — Rich Menu 圖檔設計需求

## 用途

LINE 1-on-1 對話下方常駐選單。使用者打開 Laiki Bot 聊天室即看到。每位 follower 預設啟用。

## 規格

| 項目 | 值 |
|---|---|
| 尺寸 | **2500 × 1686 px** (必須精準,不可縮放) |
| 解析度 | 72 dpi |
| 色彩 | RGB (sRGB) |
| 格式 | JPEG (建議) 或 PNG |
| 檔案大小 | ≤ **1 MB** |
| 出稿 | 1 張完整圖 (不切片) |

## 版面: 2 列 × 3 欄

每格 833 × 843 px (右欄 834 px 補齊)。

## 視覺風格

### 主色
- **主綠**: `#1DB446` (Laiki 品牌綠,Flex 卡片同色)
- 輔助綠: `#0E8C32` (深) / `#A7E5BA` (淺)
- 中性: `#FFFFFF` 底 + `#333333` 文字 + `#999999` 副標
- 警示/收入: `#F59E0B` (橘) — 慎用

### 風格方向
- **乾淨白底**,綠色 accent
- 圖示用 **outline / line icon** 風格 (細描邊,2-3 px 線寬@2500 寬)
- 不要 gradient 重彩,避免 LINE 縮圖糊掉
- 不要寫實照片
- 圖示 + 文字垂直置中,圖示在上 (約佔格高 45%),文字在下 (約佔格高 25%)

### 字型
- 中文: 思源黑體 / 蘋方 / Noto Sans TC,**Bold/Medium**
- 字級 (in 2500 px 畫布):
  - 主標 `記一筆` 等: **64-72 px**
  - 副標: 36-40 px (選用)
- 字色: `#222222`,綠 accent 可用

### 分隔
- 格與格之間用 **1-2 px** `#E5E5E5` 細線 或 留 24-32 px 白邊
- 不要厚框

### 邊距
- 每格內容**距格邊至少 60 px** (LINE 觸控區域略大於視覺區,邊緣留白避免誤觸感)
- 圖示佔格中央約 240 × 240 px

## 不要做的事

- ❌ 滿版彩色 (難讀)
- ❌ 細線 < 2 px (LINE 縮圖會消失)
- ❌ 漸層、陰影、立體效果
- ❌ 圖示用 emoji 直接放 (要設計 line icon)
- ❌ 文字超出格 (LINE 不同手機尺寸會裁切)
- ❌ 跨格的圖案 / 連續背景 (使用者只記得各自方格)

## 交付

- `richmenu.jpg` (≤ 1 MB)
- `richmenu.png` (備案,做為 master)
- 原始檔: Figma / AI / Sketch / PSD,圖層命名清楚 (`tile-1-record`, `tile-2-camera` …)

## 參考

- LINE 官方規格: https://developers.line.biz/en/docs/messaging-api/using-rich-menus/
- Laiki Flex 卡片 (色系參考): 主綠 `#1DB446`,副標 `#777777`
- 既有 onboarding Flex / menu Flex 風格延續

## 驗收標準

1. 在實機 LINE webview (iOS + Android) 開啟 Bot 對話,選單清晰可辨
2. 六格皆能單獨識別,不混淆
3. 縮圖 (LINE 列表頁) 預覽不糊
4. 不同膚色/深色模式皆 OK (LINE 無深色模式,但避免純白爆光)

## 上傳

設計師提供 jpg 後,工程上傳:
```bash
docker compose exec server node dist/scripts/uploadRichMenuImage.js <richMenuId> /path/to/richmenu.jpg
```
